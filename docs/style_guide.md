# Руководство по стилю интерфейса

Все окна приложения «Семейный бюджет» оформляются по единым правилам.
Значения задаются в одном месте — в файле `app/ui/styles.py`.

## Цветовая схема

| Назначение | Цвет | Код |
|------------|------|-----|
| Основной (кнопки действий, заголовки таблиц) | зелёный | `#2E7D32` |
| Основной тёмный (заголовки окон, наведение) | тёмно-зелёный | `#1B5E20` |
| Акцент (выделенная строка таблицы, монета в логотипе) | жёлтый | `#FFD54F` |
| Фон окон | светло-серый с зелёным оттенком | `#F4F7F4` |
| Фон таблиц и карточек | белый | `#FFFFFF` |
| Основной текст | почти чёрный | `#212121` |
| Подсказки | серый | `#616161` |
| Сумма доходов | зелёный | `#2E7D32` |
| Сумма расходов | красный | `#C62828` |

Зелёный цвет выбран как цвет денег и стабильности, красный используется только для расходов.

## Шрифты

Основной шрифт — **Segoe UI** (системный шрифт Windows).

| Элемент | Размер | Начертание |
|---------|--------|------------|
| Заголовок окна | 16 | полужирный |
| Подзаголовок, итоги | 12 | полужирный |
| Суммы на карточках главного окна | 18 | полужирный |
| Основной текст, поля ввода, кнопки | 10 | обычный |
| Подсказки под полями | 8 | курсив |

## Логотип и иконка

- Логотип: зелёный квадрат со скруглёнными углами, белый дом и жёлтая монета со знаком рубля.
- Файлы: `resources/logo.png` (64×64, главное окно, левый верхний угол),
  `resources/icon.png` (32×32, иконка всех окон), `resources/icon.ico` (иконка .exe-файла).
- Иконка задаётся один раз для всего приложения функцией `set_application_icon`.

## Компоновка окон

- Каждое окно имеет понятный заголовок вида «Раздел — Семейный бюджет».
- Минимальный размер окон разделов — 960×600, главного окна — 640×440.
- При увеличении окна растягивается таблица с данными, панель формы сохраняет ширину.
- Слева — таблица с данными, справа — панель формы «Данные …» с полями и кнопками.
- Подписи полей расположены над полями, подсказки — под полями.
- Обязательные поля отмечены звёздочкой `*`.
- Значения из справочников выбираются из выпадающих списков (только чтение).
- Основное действие в форме («Добавить») выделено зелёной кнопкой.
- Внизу каждого окна — кнопка «← Назад в главное меню» (также клавиша Esc).
- Порядок перехода по Tab — сверху вниз и слева направо, кнопка «Назад» последняя.

## Сообщения пользователю

| Ситуация | Заголовок окна | Значок |
|----------|----------------|--------|
| Ошибка ввода | «Ошибка ввода» | ошибка |
| Запрещённое действие, не выбрана строка | «Предупреждение» | предупреждение |
| Успешное действие, пустой результат поиска | «Информация» | информация |
| Удаление, выход, отрицательный баланс | «Подтверждение» | предупреждение, кнопки Да/Нет |
| Непредвиденная ошибка | «Непредвиденная ошибка» | ошибка |

Текст сообщения всегда объясняет, что случилось и что сделать пользователю.
