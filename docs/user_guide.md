# Руководство пользователя

Приложение «Семейный бюджет». Документ составлен по структуре РД 50-34.698-90
«Автоматизированные системы. Требования к содержанию документов» (раздел «Руководство пользователя»).

## 1. Введение

### 1.1 Область применения

Приложение используется в домашних условиях для учёта денежных средств семьи:
поступлений (зарплата, подработка и т. п.) и трат (продукты, коммунальные услуги, транспорт и т. п.).

### 1.2 Краткое описание возможностей

- ведение журнала доходов и расходов;
- ведение справочников категорий и членов семьи;
- просмотр итогов и текущего баланса;
- построение отчёта по категориям за период и сохранение его в файл.

### 1.3 Уровень подготовки пользователя

Пользователь должен уметь работать с окнами, мышью и клавиатурой в ОС Windows.
Специальных знаний не требуется.

### 1.4 Перечень эксплуатационной документации

- настоящее руководство пользователя;
- файл README.md с инструкцией по установке.

## 2. Назначение и условия применения

Приложение предназначено для автоматизации учёта семейного бюджета.

Условия применения:

- компьютер с ОС Windows 10/11 (или Linux/macOS);
- Python 3.10 и новее (не нужен для .exe-версии);
- разрешение экрана не менее 1024×768;
- право записи в папку программы (там хранится база данных).

## 3. Подготовка к работе

### 3.1 Состав дистрибутива

- `main.py` и папка `app` — программа;
- `resources` — логотип и иконки;
- `run.bat` — файл запуска;
- `tools/fill_demo_data.py` — заполнение примерами (необязательно).

### 3.2 Запуск программы

1. Дважды щёлкните по файлу `run.bat` (или по `FamilyBudget.exe` для собранной версии).
2. Откроется главное окно «Семейный бюджет — главное меню».

### 3.3 Проверка работоспособности

Программа работоспособна, если открылось главное окно с тремя карточками
(«Все доходы», «Все расходы», «Баланс семьи») и пятью кнопками меню.
При первом запуске суммы равны «0,00 ₽», а в разделе «Категории» есть шесть стандартных категорий.

## 4. Описание операций

### 4.1 Добавление члена семьи

1. В главном меню нажмите «Члены семьи».
2. Введите ФИО (только буквы, пробел и дефис) и роль в семье.
3. Нажмите «Добавить». Появится сообщение «Член семьи успешно добавлен».

### 4.2 Добавление категории

1. В главном меню нажмите «Категории».
2. Введите название и выберите тип «Доход» или «Расход».
3. Нажмите «Добавить». Повторяющиеся названия не допускаются.

### 4.3 Добавление операции

1. В главном меню нажмите «Операции (доходы и расходы)».
2. Проверьте дату (по умолчанию — сегодня), введите сумму, например `1500` или `249,90`.
3. Выберите категорию и члена семьи из выпадающих списков, при желании введите комментарий.
4. Нажмите «Добавить».
5. Если расход больше текущего баланса, программа попросит подтверждение.

### 4.4 Изменение и удаление записи

1. Выберите строку в таблице — её данные появятся в форме справа.
2. Для изменения исправьте поля и нажмите «Сохранить».
3. Для удаления нажмите «Удалить» и подтвердите действие.
4. Кнопка «Очистить» очищает форму для ввода новой записи.

### 4.5 Поиск и фильтрация операций

1. В окне «Операции» выберите тип в списке «Тип» (Все / Доход / Расход).
2. Введите текст в поле «Поиск» и нажмите «Найти» или Enter. Поиск идёт по комментарию,
   категории и ФИО, регистр букв не важен.
3. «Сбросить» возвращает полный список.

### 4.6 Отчёт по категориям

1. В главном меню нажмите «Отчёт по категориям».
2. Укажите период «с» и «по» в формате ДД.ММ.ГГГГ и нажмите «Сформировать».
3. Для сохранения нажмите «Сохранить в CSV» и выберите папку. Файл открывается в Microsoft Excel.

### 4.7 Завершение работы

Нажмите «Выход» в главном меню (или закройте окно) и подтвердите выход.
Все данные сохраняются автоматически сразу после каждого действия.

## 5. Аварийные ситуации

| Ситуация | Что делать |
|----------|-----------|
| Окно «Ошибка ввода» | Прочитайте сообщение и исправьте указанное поле |
| «Нельзя удалить категорию / члена семьи» | Сначала удалите или измените связанные операции |
| «Непредвиденная ошибка» | Повторите действие; при повторении перезапустите программу. Подробности — в `data/errors.log` |
| «Не удалось открыть файл базы данных» | Переместите программу в папку, доступную для записи (например, «Документы») |
| Нужно начать учёт заново | Закройте программу и удалите файл `data/family_budget.db` |

Для резервного копирования достаточно скопировать файл `data/family_budget.db`.

## 6. Рекомендации по освоению

1. Запустите `python tools/fill_demo_data.py`, чтобы заполнить базу примерами.
2. Посмотрите итоги на главном экране, затем откройте «Операции» и попробуйте фильтр и поиск.
3. Постройте отчёт по категориям за последний месяц.
4. Удалите демонстрационную базу (`data/family_budget.db`) и начните вести свой бюджет.
